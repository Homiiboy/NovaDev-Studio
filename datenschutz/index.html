Datenschutz

Allgemeines

Der Schutz persönlicher Daten ist uns ein wichtiges Anliegen. Personenbezogene Daten werden im Rahmen dieser Website nur verarbeitet, soweit dies für den Betrieb der Website oder die Bearbeitung von Anfragen erforderlich ist und eine entsprechende Rechtsgrundlage besteht.

Kontaktformular

Wenn du über das Kontaktformular Kontakt aufnimmst, werden die von dir eingegebenen Daten zur Bearbeitung deiner Anfrage verarbeitet. Das Formular wird technisch über Formspree bereitgestellt. Dabei können Daten an diesen Dienst übermittelt und dort verarbeitet werden.

Hosting und Server-Logdaten

Beim Aufruf dieser Website können durch den Hosting-Anbieter technisch erforderliche Daten verarbeitet werden, insbesondere IP-Adresse, Zeitpunkt des Zugriffs, aufgerufene Seite sowie Browser- und Geräteinformationen. Diese Daten dienen insbesondere dem sicheren und stabilen Betrieb der Website.

Externe Schriftarten

Diese Website verwendet Google Fonts. Beim Laden der Schriftarten kann eine Verbindung zu Servern von Google hergestellt werden. Dabei können technische Verbindungsdaten verarbeitet werden.

Externe Links

Die Website enthält Verlinkungen zu externen Angeboten, beispielsweise Instagram. Erst beim Aufruf dieser Links gelten die Datenschutzbestimmungen des jeweiligen Anbieters.

Deine Rechte

Nach Maßgabe der gesetzlichen Voraussetzungen stehen dir insbesondere Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung, Datenübertragbarkeit und Widerspruch zu.
